# UrFU-Diplom-2026
Как пользоваться программой

1. Установите зависимости:
   pip install networkx matplotlib

2. Перейдите в каталог проекта:
   cd gamilthon

3. Запустите программу:
   python main.py

4. После запуска выберите режим работы:
   1 - поиск исключений без ограничения по числу итераций;
   2 - поиск исключений с ограничением по числу итераций;
   3 - одиночная проверка для выбранных параметров.

5. Если выбран режим 1 или 2:
   - введите максимальное значение n для проверки гамильтонова цикла;
   - для режима 2 дополнительно введите максимальное число итераций;
   - программа будет перебирать параметры n и k, выводить статистику по каждой итерации и при завершении сохранит отчет.

6. Если выбран режим 3:
   - введите четное значение n;
   - введите значение k от 1 до n - 1;
   - программа построит граф Кэли, выполнит проверку и отобразит результат.

7. После завершения поиска создается текстовый отчет в папке `reports/` вида:
   reports/gamilthon_report_YYYYMMDD_HHMMSS.txt

8. В отчете сохраняются:
   - количество выполненных итераций;
   - общее время вычислений;
   - число непорождающих систем;
   - число проверок на гамильтоновость;
   - информация о найденном исключении или сообщение о его отсутствии.
