# UrFU-Diplom-2026

Программа для построения графов Кэли диэдральных групп и поиска
гамильтоновых циклов. В прикладной интерпретации такой граф рассматривается
как модель веб-графа: элементы группы соответствуют веб-страницам, а ребра
графа Кэли соответствуют допустимым переходам по гиперссылкам.

## Установка

```bash
python3 -m pip install -r requirements.txt
```

Или вручную:

```bash
python3 -m pip install networkx matplotlib
```

## Запуск

```bash
python3 main.py
```

После запуска доступны режимы:

1. Поиск исключений без ограничения по числу итераций.
2. Поиск исключений с ограничением по числу итераций.
3. Одиночная проверка для выбранных параметров.
4. CSV-эксперимент для получения таблицы результатов.
5. Подготовка дипломных примеров с PNG-иллюстрациями.
6. Сбор страниц существующего сайта в файл.

В режимах, где выполняется поиск гамильтонова цикла, можно задать лимит
времени на одну проверку. Если лимит не указан, поиск идет без ограничения по
времени для каждой отдельной системы порождающих.

## Семейства систем порождающих

Для четного `n` строится диэдральная группа `D_n`. Программа поддерживает
несколько семейств систем порождающих.

Базовое семейство связано с теоремой о трех инволюциях:

```text
g1 = r0s
g2 = r(n/2)s
g3 = rks
```

Для него проверяются следующие свойства:

- все три генератора являются инволюциями;
- первые две инволюции `g1` и `g2` коммутируют;
- генераторы различны;
- система порождает всю группу `D_n`;
- в графе Кэли найден гамильтонов цикл.

Важно: третья инволюция не обязана коммутировать с первыми двумя. Для
теоремы из постановки задачи требуется только коммутативность пары `g1`, `g2`.

CSV-эксперимент также умеет перебирать дополнительные семейства:

- поворот, обратный поворот и отражение: `S = {r^a, r^-a, r^b s}`;
- две отражающие симметрии: `S = {r^a s, r^b s}`.

Эти семейства нужны для исследования графов Кэли, построенных по различным
системам порождающих.

## Поиск гамильтонова цикла

Поиск гамильтонова цикла выполняется обходом с возвратом. Для практических
экспериментов программа сохраняет не только факт наличия цикла, но и статус
проверки:

- `found` — гамильтонов цикл найден;
- `not_found` — поиск завершился полным перебором без найденного цикла;
- `timeout` — поиск остановлен по лимиту времени;
- `skipped` — проверка цикла не запускалась.

Также фиксируются число просмотренных состояний и время, потраченное именно
на поиск цикла. Важно: `timeout` не считается контрпримером, потому что он
означает только нехватку времени на проверку.

## Веб-интерпретация

Найденный цикл выводится в двух видах:

```text
e -> r0s -> r2 -> ...
```

и как маршрут по страницам:

```text
/page/e -> /page/r0s -> /page/r2 -> ...
```

Такой маршрут можно трактовать как обход всех страниц моделируемого веб-графа
ровно по одному разу с возвратом в начальную страницу.

Также можно передать файл со своими страницами. Формат файла: по одной
странице или URL на строку, пустые строки и строки с `#` в начале пропускаются.
Страниц должно быть не меньше, чем вершин в группе `D_n`, то есть не меньше
`2n`.

Пример:

```text
examples/pages_D4.txt
```

Если файл указан, программа дополнительно выводит маршрут по этим страницам.

Страницы можно не готовить вручную. Режим `6` принимает стартовый URL
существующего сайта, автоматически собирает внутренние HTML-страницы и
сохраняет их в файл:

```text
reports/site_pages_YYYYMMDD_HHMMSS.txt
```

Crawler использует найденные HTML-ссылки, по умолчанию оставляет только
страницы того же домена и отбрасывает технические ссылки вроде `mailto:`,
`tel:`, PDF, изображений, архивов и других файлов. Полученный файл затем можно
указать в одиночной проверке, CSV-эксперименте или подготовке дипломных
примеров.

Важно: реальные страницы используются как вершины моделируемого веб-графа.
Структура переходов для гамильтонова маршрута по-прежнему задается графом Кэли.

## Отчеты

После завершения поиска создается текстовый отчет:

```text
reports/gamilthon_report_YYYYMMDD_HHMMSS.txt
```

В отчете сохраняются:

- количество выполненных итераций;
- общее время вычислений;
- число систем вне условий теоремы;
- число непорождающих систем;
- число проверок на гамильтоновость;
- число проверок, остановленных по лимиту времени;
- последний найденный гамильтонов цикл;
- веб-маршрут последнего найденного цикла;
- информация о найденном исключении или сообщение о его отсутствии.

Одиночная проверка дополнительно сохраняет изображение графа с подсвеченным
гамильтоновым циклом:

```text
reports/gamilthon_graph_Dn_kK_YYYYMMDD_HHMMSS.png
```

CSV-эксперимент создает таблицу:

```text
reports/gamilthon_experiment_YYYYMMDD_HHMMSS.csv
```

В CSV сохраняются семейство системы, параметры генераторов, `n`, `k`, размер
группы и порожденной подгруппы, генераторы, выполнение условий теоремы,
результат поиска гамильтонова цикла, статус проверки, число просмотренных
состояний, время поиска, сам цикл, соответствующий модельный веб-маршрут и
маршрут по страницам из файла, если файл был указан.

Также рядом с CSV сохраняется сводный текстовый отчет:

```text
reports/gamilthon_summary_YYYYMMDD_HHMMSS.txt
```

В нем есть общая статистика, статистика по семействам систем порождающих и
статистика по значениям `n`.

Режим подготовки дипломных примеров сохраняет по одному найденному примеру для
выбранных семейств:

```text
reports/diploma_examples_YYYYMMDD_HHMMSS/
```

В папке лежат PNG-графы с подсвеченными гамильтоновыми циклами и файл
`examples_summary.txt` с параметрами, генераторами, циклом и веб-маршрутом.
